# Технічне завдання

## Назва проєкту
Soft Light — вебзастосунок фотостудії для перегляду фотозалів та онлайн-бронювання.

## Проблема
Користувачам необхідно зручно переглядати інформацію про фотозали, доступний час та оформлювати бронювання.

## Мета та цільова аудиторія
Мета проєкту — створити зручний вебзастосунок для перегляду фотозалів та онлайн-бронювання.
Цільова аудиторія:
- фотографи;
- моделі;
- клієнти фотостудії.

## Ролі користувачів
- Гість;
- Користувач;
- Адміністратор.

## Основні функції
- перегляд фотозалів;
- перегляд фотографій та характеристик;
- перегляд доступного часу;
- реєстрація та авторизація;
- вибір дати та часу;
- оформлення бронювання;
- введення контактних даних;
- внесення передоплати;
- перегляд та керування бронюваннями;
- керування фотозалами, бронюваннями та користувачами адміністратором.

## Функціональні вимоги
- система повинна забезпечувати перегляд фотозалів;
- система повинна відображати доступний час;
- користувач повинен мати можливість оформити бронювання;
- користувач повинен мати можливість переглядати власні бронювання;
- адміністратор повинен мати можливість керувати фотозалами, бронюваннями та користувачами.

## Нефункціональні вимоги
- адаптивне відображення вебзастосунку;
- зрозуміла навігація;
- захист даних користувачів;
- коректна робота основних функцій;
- використання HTTPS.

## Обмеження проєкту
- вебзастосунок розробляється як навчальний проєкт;
- система працює в межах визначеного функціоналу;
- онлайн-оплата реалізується як передоплата;
- адміністрування доступне лише авторизованому адміністратору.

## Критерії готовності першої версії
- реалізовано основні сторінки;
- доступний перегляд фотозалів;
- реалізовано бронювання;
- реалізовано реєстрацію та авторизацію;
- доступний особистий кабінет користувача;
- реалізовано панель адміністратора.

## Основні сторінки
- Головна сторінка;
- Фотозали;
- Сторінка фотозалу;
- Бронювання;
- Вхід та реєстрація;
- Особистий кабінет;
- Технічна підтримка;
- Панель адміністратора.
