# Soft Light
Вебзастосунок фотостудії Soft Light для перегляду фотозалів, перевірки доступного часу та оформлення бронювання.

## Проблема
Користувачам необхідно зручно переглядати інформацію про фотозали та доступний час, а також швидко оформлювати бронювання без додаткового звернення до адміністрації.

## Мета та цільова аудиторія
Мета проєкту — створити зручний вебзастосунок для перегляду фотозалів та онлайн-бронювання.

Цільова аудиторія:
- фотографи;
- моделі;
- клієнти фотостудії.

## Ролі користувачів
- **Гість** — перегляд фотозалів та доступної інформації.
- **Користувач** — перегляд фотозалів, вибір дати й часу та оформлення бронювання.
- **Адміністратор** — керування фотозалами, бронюваннями та користувачами.

## Основні функції
- перегляд фотозалів;
- перегляд фотографій та характеристик залів;
- перегляд доступного часу;
- реєстрація та авторизація;
- вибір дати та часу;
- оформлення бронювання;
- введення контактних даних;
- внесення передоплати;
- перегляд та керування власними бронюваннями;
- керування фотозалами, бронюваннями та користувачами адміністратором.

## Основні сторінки
- Головна сторінка;
- Фотозали;
- Сторінка фотозалу;
- Бронювання;
- Вхід та реєстрація;
- Особистий кабінет;
- Технічна підтримка;
- Панель адміністратора.
