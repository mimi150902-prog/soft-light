# Користувацькі сценарії

## Сценарій 1 — Гість
**Мета:** переглянути доступні фотозали.
**Початкові умови:** користувач не авторизований.
**Дії користувача:**
1. Відкриває головну сторінку.
2. Переходить до розділу «Фотозали».
3. Обирає потрібний фотозал.
**Реакція системи:** система відображає інформацію про фотозал та його характеристики.
**Очікуваний результат:** гість переглянув інформацію про фотозал.
**Альтернатива:** якщо інформація недоступна, система повідомляє про помилку завантаження.

## Сценарій 2 — Користувач
**Мета:** оформити бронювання фотозалу.
**Початкові умови:** користувач авторизований.
**Дії користувача:**
1. Обирає фотозал.
2. Обирає дату та доступний час.
3. Вводить контактні дані.
4. Підтверджує бронювання.
5. Вносить передоплату.
**Реакція системи:** система перевіряє доступність часу та створює бронювання.
**Очікуваний результат:** бронювання створено.
**Альтернатива:** якщо обраний час уже зайнятий, система пропонує обрати інший час.

## Сценарій 3 — Адміністратор
**Мета:** опрацювати бронювання.
**Початкові умови:** адміністратор авторизований.
**Дії користувача:**
1. Відкриває панель адміністратора.
2. Переглядає список бронювань.
3. Обирає потрібне бронювання.
4. Змінює його статус.

**Реакція системи:** система перевіряє права адміністратора та зберігає зміни.
**Очікуваний результат:** бронювання опрацьовано.
**Альтернатива:** якщо дані некоректні, система повідомляє про помилку.
